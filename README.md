# Computer Vision Experiments

This repository contains a collection of Computer Vision experiments, ranging from fundamental image processing techniques to geometric and content-based image analysis.

The project focuses on implementing, comparing, and evaluating different methods rather than building a complete production application.

## Project Scope

### Project 1: Image Processing Fundamentals

- Color images, grayscale images, and color channels
- Low-pass and high-pass filtering
- Geometric transformations: translation, rotation, scaling, affine, and projective transformations

### Project 2: Image Editing and Geometric Analysis

- Gradient Domain Editing and Poisson blending
- Feature extraction and matching with SIFT and ORB
- Homography estimation with RANSAC
- Panorama image stitching

### Integrated Project

- Image preprocessing
- Geometric and scene-structure analysis
- Object detection or instance segmentation using pretrained models
- Visualization, comparison, and experimental evaluation

## Installation

```bash
git clone https://github.com/nguyenlionelv/cv-experiments-from-ipcv-vingroup.git
cd <your_folder>
pip install -r requirements.txt
```

## Usage

Run the notebooks in the following order:

1. Image processing fundamentals
2. Gradient Domain Editing
3. Panorama stitching
4. Integrated geometric and content analysis

The experiments can be executed locally, on Google Colab, or on Kaggle Notebook.

## Main Technologies

- Python
- NumPy
- OpenCV
- Matplotlib
- PyTorch or another deep learning framework for pretrained models

## Evaluation

Each experiment includes visual comparisons, quantitative metrics where appropriate, and a discussion of successful and failed cases.
